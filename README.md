# skootle-actors-assets

Public CDN for Apify Store actor visuals (icons + hero banners).
Used in actor README markdown via raw GitHub URLs.

## Layout
- `icons/` — 1024×1024 actor icons (edge-to-edge, no white frame)
- `heroes/` — 1600×600 hero banners for README headers
